# Mockups — site de reserva direta (Porto de Galinhas)

Três direções para apresentar ao proprietário. Mesmo conteúdo (dados reais do anúncio), visuais diferentes.

| Arquivo | Direção | Nome sugerido |
|---|---|---|
| `tropical.html` | Resort tropical | Villa Coqueiral |
| `cinema.html` | Cinematográfico | Villa Maré |
| `boutique.html` | Boutique minimal | Casa Dez |

- Fotos: `photos/` (recortadas das capturas da galeria, 974 × 716).
- Reserva: o formulário monta a mensagem e abre `wa.me` sem número; trocar pelo WhatsApp do proprietário.
- Os arquivos não têm `<!doctype>`/`<head>` porque são publicados como Artifact (claude.ai), que adiciona o esqueleto.
