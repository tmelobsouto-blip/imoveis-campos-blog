# Processo: do anúncio ao site vendido

1. **Escolher o imóvel.** Casa de temporada bem avaliada, sem site próprio. Copiar o link do anúncio.
2. **Coletar material.** Prints da galeria de fotos (todas que der) e das telas do anúncio: título,
   capacidade, quartos e camas, comodidades, regras e observações, nota, avaliações, anfitrião, localização
   e um valor total de estadia.
3. **Entrevista (grill).** Objetivo do site, público, como será apresentado, idioma, seções. Ver a skill
   `novo-cliente`.
4. **Preparar os dados.** `clientes/<slug>/fonte/` com os prints, `npm run fotos` para recortar,
   `dados.md` com os fatos.
5. **Três mockups.** Direções visuais diferentes com o mesmo conteúdo real. Publicar e mandar os links.
6. **Site final.** Combinar o que o usuário escolher. Checar com `npm run check`.
7. **Proposta.** Página + PDF com a conta da taxa, pacotes ([precos.md](precos.md)) e próximos passos.
   Dados do vendedor preenchidos.
8. **Envio.** Usuário compartilha os links (menu Share) e manda proposta + site ao proprietário.
9. **Fechamento.** Proprietário escolhe pacote, envia número de WhatsApp, fotos originais e aprova o nome.
10. **Publicação.** Domínio no nome do proprietário, hospedagem com uso comercial permitido
    (ex.: Cloudflare Pages), WhatsApp real no botão, entrega dos acessos.
